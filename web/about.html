About this app

A personal tool

Game Spec Check was made for the author's own use and is shared as is. It comes with no support, no promise of updates and no warranty.

Built with AI

The code was written by Claude, an AI model from Anthropic, through Claude Code, following the author's instructions. It has not had a professional review or a security audit, and some of its answers will be wrong. The speed scores for processors and graphics cards are rough estimates.

Privacy

Details about this PC stay on this PC, and so do the games it finds and where they are installed. Finding games only reads launcher records, installed-program records, Start menu shortcuts and folders you add. Nothing is run while scanning, and no account or sign-in is needed.

The only network requests are lookups to Steam and PCGamingWiki, which carry a game's id or a title to search for. Their answers are cached on this PC. Profiles, wanted games, the games you matched by hand and the last scan are saved in a local folder. Report images are made on this PC and leave out user names and install folders.
